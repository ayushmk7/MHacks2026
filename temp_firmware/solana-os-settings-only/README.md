# Solana OS: Settings Only

Based on [Solana OS](https://github.com/spacemandev-git/solana-defcon-badge-26/tree/main/firmware/solana-os), upstream commit `812b8c7aca5c366d18c0b040fafd2999f7204d84`.

This variant boots directly to the native Settings menu, disables app autostart,
and includes no bundled Lua games or demos. Hardware support and the Identity,
Wi-Fi, Bluetooth, ESP-NOW, display, LED, device info, and console settings remain.
The upstream app runtime and app-push support are retained, but no apps are
included in this copy.

## Build

Requires Arduino ESP32 core 3.x and LovyanGFX. From this directory:

```sh
arduino-cli compile --fqbn "esp32:esp32:esp32s3:PSRAM=opi,FlashSize=16M,PartitionScheme=custom,CDCOnBoot=cdc" --output-dir build .
arduino-cli upload --fqbn "esp32:esp32:esp32s3:PSRAM=opi,FlashSize=16M,PartitionScheme=custom,CDCOnBoot=cdc" -p /dev/cu.usbserial-XXXX .
```

For a web flash page, select the merged image generated by the compile command:
`build/solana-os-settings-only.ino.merged.bin` (16 MiB, full flash image).

The flash command is provided for operators; this project change does not flash
or alter a connected badge.

## Load an app

An app is a folder with a `main.lua` entry point and optional `app.ini` and
assets. The folder name becomes the app ID; IDs use lowercase letters, digits,
`.`, `_`, or `-` (up to 32 characters).

1. On the badge, open **Settings → Wi-Fi** and connect to a network or start
   the badge hotspot.
2. Open **Settings → App push**. When Wi-Fi is connected, the screen shows the
   browser address and six-digit pairing code.
3. From a device on the same network, open that address. Use **Push an app** to
   upload one Lua file, or use the host tool below to upload a whole app folder.
4. Press CANCEL to return to the launcher. Select an installed app to run it.

The included host tool uses Python's standard library for Wi-Fi uploads:

```sh
python3 tools/badge-push.py --host <badge-address> --token <pairing-code> push path/to/my-app --run
```

For example, `path/to/my-app/main.lua` is the entry script. `--run` is optional;
without it, the app installs and appears in the launcher. Apps persist on the
badge's LittleFS across reboots and can be managed from the browser page or with
`list` and `rm` commands in `badge-push.py`. BLE upload is also supported and
requires the optional `bleak` Python package.
